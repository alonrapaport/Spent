# Libi Simcha birth announcement

A self-contained, single-page digital invitation (Hebrew, right to left) celebrating the birth of Libi Simcha, daughter of Yael and Alon Rapaport. Built to be shared on WhatsApp and read comfortably on a phone.

- `index.html` - the entire invitation (markup + embedded CSS, Google Fonts, inline SVG art). No build step required: open it directly in a browser.
- `libi.jpg` - the featured photo.

The event details (Friday, 26.06.26, 11:30, Rishi 19 Apt 1, Beit Shemesh) include one-tap Waze and Google Maps links.
